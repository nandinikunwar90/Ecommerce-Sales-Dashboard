# Ecommerce-Sales-Dashboard
Interactive E-Commerce Sales Dashboard built using Power BI and Python for sales analysis, KPI tracking, and business insights.

## Project Overview
This project analyzes e-commerce sales data using Python and Power BI. The dataset was cleaned and explored in Jupyter Notebook, and an interactive dashboard was created in Power BI to visualize key business metrics and generate actionable insights.

## Tools & Technologies
- Python
- Pandas
- Jupyter Notebook
- Power BI
- Power Query

## Project Workflow
1. Data Cleaning and Preprocessing using Python (Pandas).
2. Exploratory Data Analysis (EDA) in Jupyter Notebook.
3. Data Import and Transformation in Power BI.
4. Dashboard Development using Power BI visuals.
5. Business Insights Generation.

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity Sold KPI
- Sales by Category
- Sales by Region
- Sales Trend Analysis
- Sales by Segment
